# BlockFit
BlockFit is an absent-minded game where the user picks up blocky shapes and places them within a 9x9 grid. Filling a row or column clears it, and filling multiple rows and/or columns at the same time earns more points than filling them individually.

I made this game in recreation of other similar games I found myself playing when I needed to keep my hands busy. I thought it would be cool to have my own version that I could build upon and make changes to. Currently, the user is able to:
- Pick and place shapes.
- Rotate shape pieces.
- Preview placement.
- Hold a piece for later.

In the future, if I have time to spare, I plan to add the following features:
- A form of progression.
- An item store for points gained.
- High scores.
- Saving.
